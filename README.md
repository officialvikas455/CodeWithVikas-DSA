## ⚙️ How to Run

### 🔧 Prerequisites
- ✅ C++ Compiler — GCC / G++
- ✅ VS Code / Code::Blocks / CLion / Any IDE

### 💻 Steps

```bash
# 📥 Step 1: Clone the Repository
git clone https://github.com/officialvikas455/CodeWithVikas-DSA.git

# 📂 Step 2: Navigate to topic folder
cd CodeWithVikas-DSA/01_Arrays

# 🛠️ Step 3: Compile the program
g++ basics.cpp -o output

# ▶️ Step 4: Run the program
./output

## 🧠 Algorithms Complexity Cheat Sheet

```
╔══════════════════════════════════════════════════════════════════════╗
║  Algorithm        │ Best      │ Average   │ Worst    │ Space        ║
╠══════════════════════════════════════════════════════════════════════╣
║  Bubble Sort      │ O(n)      │ O(n²)     │ O(n²)    │ O(1)        ║
║  Selection Sort   │ O(n²)     │ O(n²)     │ O(n²)    │ O(1)        ║
║  Insertion Sort   │ O(n)      │ O(n²)     │ O(n²)    │ O(1)        ║
║  Merge Sort       │ O(nlogn)  │ O(nlogn)  │ O(nlogn) │ O(n)        ║
║  Quick Sort       │ O(nlogn)  │ O(nlogn)  │ O(n²)    │ O(logn)     ║
║  Heap Sort        │ O(nlogn)  │ O(nlogn)  │ O(nlogn) │ O(1)        ║
║  Binary Search    │ O(1)      │ O(logn)   │ O(logn)  │ O(1)        ║
║  BFS / DFS        │ O(V+E)    │ O(V+E)    │ O(V+E)   │ O(V)        ║
║  Dijkstra         │ O(V²)     │ O(ElogV)  │ O(ElogV) │ O(V)        ║
╚══════════════════════════════════════════════════════════════════════╝
