- 🎓 Students learning DSA from scratch

## ⚙️ How to Run

### Prerequisites
- C++ compiler (GCC / G++ recommended)
- Any IDE: VS Code, Code::Blocks, or CLion

### Compile & Run

```bash
# Clone the repository
git clone https://github.com/officialvikas455/CodeWithVikas-DSA.git

# Navigate to the folder
cd CodeWithVikas-DSA

# Compile any file
g++ filename.cpp -o output

# Run
./output
```
